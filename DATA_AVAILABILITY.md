# Data availability

The confidential administrative KOSGEB firm-level source dataset is **not included** in this archive. It contains institutionally protected firm-level information and was supplied for the underlying academic study. This public-safe archive contains no KOSGEB-derived numerical result file. It contains deterministic synthetic data generated at runtime, a non-sensitive deaR fixture embedded in the R replication script, and frozen verification summaries from native `Benchmarking` and `deaR` runs.

No firm names, tax identifiers, or confidential KOSGEB row-level records are required to run the public test suite.
