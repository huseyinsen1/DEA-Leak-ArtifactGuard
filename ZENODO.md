# Zenodo archiving plan

After the repository is made public:

1. Create the GitHub release tag `v2.0.0`.
2. Connect/enable the repository in Zenodo, or upload the release archive manually.
3. Use resource type **Software**.
4. Use the title:
   **DEA-Leak and DEA ArtifactGuard 2.0: Public-Safe Reproducibility Package**
5. Creator:
   **Hüseyin Şen**, ORCID `0000-0002-3284-9629`.
6. Version: `2.0.0`.
7. License: **MIT**.
8. Do not upload confidential KOSGEB source data.
9. Publish/reserve the DOI.
10. Add the DOI back to `README.md`, `CITATION.cff`, and the manuscript.

The DOI should identify the frozen release used for the article, not a moving development branch.
